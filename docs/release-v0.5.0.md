Silver Pines Coop **0.5.0 候选版**新增 Steam 双人共享储物箱，以及队友暂停/过场状态提示。完整联机功能尚未经过真实双人 Steam 测试；请先备份存档并使用测试 profile。

连接时由房主同步储物库存初始内容；之后任一方整理储物箱，物品定义、数量、库存位置和可序列化数值状态会经房主协调后同步。个人背包、地图、血量和其他 profile 数据仍各自独立。请避免两人同时打开并整理储物箱，库存快照目前不合并同时发生的操作。本地双开共享同一存档，不能验证储物箱同步。

一方打开暂停菜单或观看过场时，另一方继续正常游玩，并在队友傀儡上方看到“正在暂停”或“正在看过场”。共同存档/回档期间的操作保护暂停仍保留。已有的 0.4.0 共同存档与死亡共同回档继续提供。

适用 Windows x64 / Steam build 25964535。双方游戏、Mod 和协议版本必须一致；协议现为 4，新增可靠消息 16 用于储物库存快照。安装完整包时解压到含 `Carpenter.exe` 的目录；已装相同版本 BepInEx be.790 的用户可用 plugin-only 包。

测试：Release 构建通过（0 警告、0 错误）；共同存档与死亡回档状态机的 29 项模拟测试通过，储物库存协议测试 3 项通过（含嵌套物品及畸形包拒绝）。实际 IL2CPP 库存重建、Addressables 加载、储物箱界面、双人 Steam 传输及状态标签定位尚待实机验证。储物箱请一人操作完再由另一人使用；发生不一致时先退出并从共同存档恢复。

Steam Deck / SteamOS / Proton 和原生 Linux 未验证。
