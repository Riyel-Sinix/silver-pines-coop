Silver Pines Coop **0.7.0** 修复玩家反馈的两个问题：道具一人捡了另一人捡不了；按 F11 同步进度不生效。双方都需要更新到 0.7.0（协议 6）。

**道具各捡各的（修复）。** 游戏里一个道具在存档中有好几条记录，例如车钥匙同时带有「交互（拾取 + 用后禁用）」和「拾取物」两部分。0.6.0 只停止同步了「拾取物」那一条，「已互动 / 已禁用」仍然同步过去，所以另一人那边道具还在却捡不了。0.7.0 按整个物体判定：只要是给玩家道具、钱、容器物品或收集品的物体，它的所有状态都各算各的。插件内置了从全部 302 个关卡场景里找出的 862 个此类物体，没去过的房间也适用。

**F11 = 互发存档（重写）。** F11 现在用游戏自己的存档格式把整份进度打包（压缩并校验）发给队友，对方在可以行动时自动按游戏的读档流程重新载入当前场景。门、谜题、剧情变量、任务、电话记录、地图探索、已死的怪等都会跟上；对方自己的背包、储物箱、位置、血量与状态、地图标记、难度，以及自己捡过 / 没捡过的道具保持不变。两人都进入存档后，房主也会自动发送一次。插件不写存档文件，满意的话自己再存一次档。0.6.0 的 F11 只能同步对方游戏里已经出现过的剧情变量，所以看起来没有效果。

另外修复：有些物体只在第一次被使用时才创建存档数据，0.6.0 不会同步这种「从无到有」的变化，现在会同步。

测试：Release 构建 0 警告 0 错误；离线测试 35 项通过（新增进度分块传输、损坏 / 乱序 / 冒名分块拒绝、存档 key 解析）；按游戏代码核对了存读档流程（`SaveSlotSegment.Serialise`、`SaveDataManager.OnLoadGameCallback`）和拾取物结构。双人实机尚未验证，遇到问题请附上双方的 `BepInEx\LogOutput.log`。

适用 Windows x64 / Steam build 26489514（也兼容 25964535）。
