Silver Pines Coop **0.4.0 候选版**新增双方共同存档与死亡共同回档。**此版本尚未经过真实双人 Steam 联机验证，请先使用测试 profile 并保留独立存档备份。**

Steam 双人联机时，任意一人使用原版保存流程选定槽位，都会请求双方保存各自的本地进度；按 F9 则由房主调用游戏自己的轮换选槽逻辑。双方暂停、交换就绪确认后保存到相同槽位索引，只有双方写盘都成功才确认最近共同存档。

有共同存档后，任意一人死亡时，双方自动一起回到最近共同存档；手动加载任意槽位也会映射为加载最近共同存档。首次共同存档前，死亡菜单仍按原版读取本地进度，恢复后再共同保存。断线后，持久化的共同存档标识、搭档和槽位匹配，且各自仍使用对应的本地 profile、槽位仍存在，才可恢复共同存档关系；不匹配时需重新共同保存。

保存或回档失败会明确提示。开始写盘或加载后失败，会清除共同存档确认，双方保持暂停并要求按 F6 退出后重新联机；已经发生的本地写盘无法自动撤销。恢复联机后重新共同保存。

**适用 Windows x64 / Steam build 25964535。双方游戏、Mod 和协议版本必须一致；协议现为 3，新增可靠消息 20…33 用于共同存档会话、准备、执行、确认和死亡通知。**

首次安装下载 `SilverPinesCoop-0.4.0-BepInEx-be790.zip`，完整解压到含 `Carpenter.exe` 的游戏目录，从 Steam 启动。已安装 BepInEx 6 be.790（IL2CPP, win-x64）可使用 `SilverPinesCoop-0.4.0-plugin-only.zip`。首次启动需生成 interop；普通玩家无需 .NET SDK。

两人先进入相同进度的存档，房主 F5 建房并邀请，好友接受 Steam 邀请；F7 再次邀请，F6 退出，F9 共同保存。请先验证双方保存完成、任一人死亡共同回档、手动加载共同回档，以及退出重连后共同存档恢复。

插件只传指令与确认，不传输存档文件。两人各自使用本地 profile；共同保存不会补齐加入前的世界差异，也不保证历史世界完全一致。怪物 AI/位置、运行时生成物、个人背包/地图/血量仍未共享；世界同步和过场同步的覆盖限制见 README。

本地双开工具共用同一份存档，关闭共同写盘与共同回档，不能验证此功能。Steam Deck / SteamOS / Proton 与原生 Linux 尚未验证。
